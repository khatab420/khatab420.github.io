📖 Overview

Afg DNS is a privacy-focused Android application that allows users to securely route their DNS queries through trusted public DNS providers. The app uses Android's built-in VPN framework to change DNS settings locally on your device. It does not provide a full VPN connection, tunnel your internet traffic, or collect any personal data.

🔐 Data Collection

Afg DNS does NOT collect, store, share, or sell any personal or non-personal user data. All DNS queries are processed locally on your device and sent directly to your selected DNS provider. No information is logged, recorded, or transmitted to any third-party servers by this application.

📱 Permissions Used

Afg DNS requires the following permissions to function properly. Each permission is explained below:

🌐 INTERNET Required to connect to DNS servers (Google DNS, Cloudflare, AdGuard, etc.) for domain name resolution. This is essential for the app's core functionality.
🔒 BIND_VPN_SERVICE Creates a local VPN connection on your device that routes DNS queries securely through your chosen DNS provider. Important: This VPN runs entirely on your device and does not tunnel your internet traffic or redirect your data to external servers.
🔄 FOREGROUND_SERVICE Allows the DNS service to run in the background while showing a persistent notification, ensuring the DNS protection remains active even when the app is not visible.
⚙️ FOREGROUND_SERVICE_SPECIAL_USE Used specifically for VPN functionality, allowing the DNS service to run as a foreground service with special use case designation for VPN operations.
📡 ACCESS_NETWORK_STATE Checks your current network connection status (WiFi, Mobile Data) to properly start, maintain, or stop DNS routing based on network availability.
🚀 RECEIVE_BOOT_COMPLETED Optional Feature – Enables the "Auto-Start on Boot" feature. If you enable this setting, the app will automatically start DNS protection when your device boots up. You can disable this feature at any time within app settings.
📋 QUERY_ALL_PACKAGES VPN Exclusion Feature – Enumerates all installed apps so you can choose which ones bypass the VPN tunnel. This is used exclusively for the app-based VPN exclusion feature in SettingsActivity.java:131-141. It lists all installed apps with a launcher intent, letting you pick which apps should bypass the DNS tunnel. Without this permission, PackageManager.queryIntentActivities() only returns apps visible to the calling app, which on API 30+ excludes most installed apps. This is a legitimate use case for a firewall/VPN app that manages per-app tunnel exclusion.
🛡️ App‑Based VPN Exclusion

The QUERY_ALL_PACKAGES permission powers the VPN exclusion feature. In SettingsActivity.java:131-141, the app lists every installed application with a launcher intent, giving you full control over which apps bypass the VPN tunnel. This is essential for a VPN/firewall app that needs to manage per‑app routing. All data is processed locally — no app list is ever sent off your device.

🎯 DNS Providers

Afg DNS supports multiple public DNS providers. You can choose from:

  • Cloudflare DNS (1.1.1.1) – Focus on speed and privacy
  • Google DNS (8.8.8.8) – Reliable and fast resolution
  • AdGuard DNS (94.140.14.14) – Blocks ads and trackers
  • CleanBrowsing (185.228.168.168) – Family-friendly content filtering
  • Quad9 (9.9.9.9) – Security-focused with threat blocking
  • Custom DNS – Add your own DNS servers

Each provider has its own privacy policy. We recommend reviewing their respective policies before use.

🔧 Technical Details

How Afg DNS works:

  • The app creates a local VPN interface that only handles DNS queries
  • Regular internet traffic continues to use your normal network connection
  • DNS queries are encrypted when using providers that support DNS-over-TLS or DNS-over-HTTPS
  • The VPN service runs locally with zero data collection or external routing
  • The VPN exclusion feature uses QUERY_ALL_PACKAGES to let you select which apps bypass the tunnel – all processed locally
